# 泛微E-Office mysql_config.ini 数据库信息泄露漏洞

## 漏洞描述

泛微 E-Office 的 `/mysql_config.ini` 文件可被未授权直接访问（缺陷编号 wooyun-2014-087500，标题"泛微Eoffice无需登录直接getshell"）。该文件包含数据库连接配置信息，攻击者无需登录即可获取数据库地址、用户名、密码等敏感信息，进而直接操作数据库获取服务器权限。

## 漏洞影响

```
泛微 E-Office
```

## 网络测绘

```
app="泛微-EOffice"
```

## 漏洞复现

直接访问：

```
GET /mysql_config.ini HTTP/1.1
```

响应中将返回数据库配置信息，包括数据库主机、用户名、密码等。攻击者可利用泄露的数据库凭证连接数据库，进一步获取系统控制权限。
