# 华夏ERP敏感信息泄漏漏洞（CNVD-2020-63964）

# 一、漏洞简介
华夏ERP基于SpringBoot框架、SaaS模式，立志为中小企业提供开源好用的ERP软件，目前专注进销存+财务功能。 华夏ERP系统存在敏感信息漏洞，攻击者可利用该漏洞获取敏感信息。

# 二、影响版本
+ 华夏ERP

# 三、资产测绘
+ hunter`web.body="jshERP-boot"`
+ 登录页面
