# 富通天下外贸ERP 任意文件上传导致命令执行漏洞(XVE-2024-8865)预警

# 漏洞描述

富通天下外贸ERPUploadEmailAttr接口处存在任意文件上传漏洞,未经身份攻击者可通过该漏洞在服务器端任意执行代码，写入后门，获取服务器权限，进而控制整个 web 服务器。

# 影响范围

富通天下外贸ERP
