# 租赁管理系统 信息泄露漏洞（CNVD-2025-03578)

# 漏洞描述

商业租赁管理系统存在严重的信息泄露漏洞，攻击者可利用该漏洞非法获取用户敏感信息，如租赁合同、客户数据等，可能导致重大经济损失和隐私泄露风险。

# 影响版本

商业租赁管理系统
