# ipTIME AX2004M 路径认证绕过与调试功能利用链（KVE-2023-0133）

## 对应关系与根因

KAIST 原始研究明确给出 AX2004M 14.19.0、KVE-2023-0133 和 timepro.cgi 路径认证缺陷，与来源对应。服务仅在请求位于 /sess-bin 时调用认证检查，但 /home/httpd/cgi/timepro.cgi 符号链接指向同一二进制，因而 /cgi/timepro.cgi 可避开该检查。完整链先重设管理密码，再开启远程支持，最后使用正常登录会话访问 d.cgi 调试入口。

## 前提、实验边界与失败记录

管理 HTTP 可达；手工正确填写验证码；先重设账号密码并启用远程支持，再取得有效会话。

这不是直接向未认证 d.cgi 发送一条命令即可完成的链。验证码需要人工回答，用户名密码及配置改变会影响原用户。原文章手工请求说 Content-Length 必须大于 0，最终脚本却使用无 body 的 GET，两种演示条件并不一致。KVE 是原研究标识，不虚构 CVE 主编号。

## 静态风险与修复

持久修改管理员账号密码与远程支持设置；多次失败登录触发验证码；通过调试功能以 root 执行命令。这些操作均不是只读检测。本次未执行 PoC、固件或依赖，未请求实验目标。外部模拟器、固件和调试二进制不因文字审阅获得安全保证。

修复记录：unknown。
