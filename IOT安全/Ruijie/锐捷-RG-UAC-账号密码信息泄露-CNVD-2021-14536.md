## 漏洞描述

锐捷RG-UAC统一上网行为管理审计系统存在账号密码信息泄露,可以间接获取用户账号密码信息登录后台

## 漏洞影响

```
锐捷RG-UAC统一上网行为管理审计系统
```

