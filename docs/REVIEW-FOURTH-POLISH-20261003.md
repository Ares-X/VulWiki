# 第四轮全库精校与前轮回归检查

本轮以 `b63c1337e59e900ab683d5ff10154a1ca2607182` 固定输入，对 5,666 篇文章做全量静态检查，并完成确认问题的局部修正。255 篇发生变化，373 处精确操作；其余 5,411 篇字节未变。只在本地修正和提交，没有推送、处理远程 PR 或发布。

## 为什么反复发现问题

主要责任在维护与验收流程。之前几轮覆盖的规则不同，重复运行旧规则不能发现尚未纳入规则的缺陷；机器扫描、候选上下文阅读和逐篇全文阅读也没有始终清楚区分。此前检查了已选入围栏的片段没有变化，却没有充分检查片段是否包括完整请求体。HTML 表格吞入后续代码起始围栏时，又可能使后面的代码与说明交替错位，局部修补不足以判断整篇。

本轮确认上轮新增了 **6 处请求范围回归**：Time Clock、CyberPanel、Altenergy、H3C iMC 的两段请求和 Palo Alto Expedition 的请求体落在新围栏之外。它们不是作者原始缺损或本轮规则的误报；已用前一提交 `cfb19294812b1435a57e866a87dd18e2ff3ebec3` 中的完整连续报文修复，包括原有空行、尾空格、公开测试值、反引号和作者截略。此前验收没有发现这些，是主维护者的失误。

低强度模型也出现了偏移换算错误、旧问题误标新回归、候选列表读取不完整，以及仅给函数声明加四空格的建议。后者会使声明与函数体复制后同级，不能采用。相关建议被撤回或重做，没有直接应用。增加模型数量不能替代明确的任务包、覆盖核对、原文绑定和结果验收；本轮仍使用 `gpt-6-luna`、`low`，由主维护者核查关键结论和最终修改。

## 实际检查覆盖

八个不重叠分片覆盖 5,666 篇，主维护者独立核对全部文件哈希与分片覆盖。132 篇优先文章接受上下文或全文审查，并有抽查；具体读取范围逐篇记录，不能将它们描述为全库人工阅读全文。37 个剩余源码候选另按 13 篇唯一文章全文复核：12 篇采用完整段落围栏，Spring Security 的 1 篇因代码与解释混在一起且来源摘录边界不明，保留原文。

255 篇修改都绑定冻结文件 SHA 和精确原文跨度。逐项逆变换证明其余字节不变；另外检查元数据、完整 HTML 表格、8 段完整请求和 23 段完整源码的静态代码 token 文本。独立表格检查的初始 Citrix 未配对告警，是扫描器误把旧围栏中的残缺 SAML 标签当成真实 HTML；专项 table 扫描纠正后，262 个目标表格全部通过，不据误报改写正文。

同一版本的持久化扫描器，修改前有 946 项候选，修改后 591 项；没有新增的 `路径 + 规则 + 原文` 候选。候选数不能当作真实错误数，修改后仍有：

## 验证结果

- Python 71 项与 Node 20 项检查通过。新 HTTP 请求体边界检查进入现有 Python 质量门禁；持久化渲染检查是静态候选工具，具体误报/待核仍须判读。
- 质量检查新增问题、错误、fatal 均为 0；5,095 条历史警告仍如实保留，其中大量是原始出处字段未知。质量基线字节未改，没有把新问题加入基线。
- 索引生成后 `build --check` 无差异。收录、排除、折叠关系和主入口目录保持一致；只有 `docs/generated/sources.jsonl` 和 `summary.json` 随内容哈希/已解决诊断更新。
- 全量核对 5,664 条来源、5,570 条主条目、2 篇排除、94 条折叠映射、15 处目录 override、10,154 条完整来源链接和 6,838 条正文 CVE 投影；来源哈希、编号角色及归属无不符。
- 隔离 Hexo 构建成功。全部 5,666 篇文章和 104 份生成文件与产物字节一致；6,427 次实际本地引用、6,130 个唯一目标与产物字节一致，新增 `config.env` 已进入产物。四份博客 Wiki UI 资源与源文件一致。
- Python 解析器余下 28 个缺失目的地候选，经上下文分类包含原站导航、代码/HTML 示例和未知归档残片。Marked 实际链接 token 中有 21 次指向 10 个不存在的目标，分别是已注明离线缺失的原站导航与正则示例；不是 21 个未补附件。19 个无效 URL 自动链接候选也单独记录，包括原作者字面值及规范化测试，不改值或访问目标。
- 原有作者占位符的有限模式检查记录 439 处完整命中及历史对照；这不是对任意历史误改的穷尽证明。正文、元数据、示例、来源、派生结果与诊断均未脱敏，已有占位值未猜补。
- 父博客原有 Obsidian 配置和 favicon 的三个保护哈希未变；没有重置、清理或覆盖用户工作。

只对字符串运行 Marked 4.3.0 lexer/parser，没有把文章 HTML 放入 DOM。代码 token 文本对照是静态复制内容检查；未验证浏览器复制按钮或实际页面交互。没有执行文章代码、PoC、扫描器、载荷或附件，没有访问示例目标，没有实际漏洞复现，也没有部署。
