# 第三轮全库精校记录

本轮以 `cfb19294812b1435a57e866a87dd18e2ff3ebec3` 为原文基准，对 5,666 篇 Markdown 做全量静态检查，修正 115 篇的 362 处排版与显示问题，并修复两项来源检索投影缺陷。文件路径、文章元数据、收录状态、编号角色和重复关系没有变化。结果保存在本地分支 `codex/wiki-third-polish-20261003`，本轮没有推送或部署。

## 覆盖范围

14 名 `gpt-6-luna / low` 审阅者分片检查全文字节、解析结果及候选问题；另有 2 名同模型、同强度审阅者检查 Git 保真和目录检索工具。所有文章均有逐文件机器记录。分片报告包含 730 篇的模型上下文阅读记录，末轮请求检查后合计 736 篇；其中一些只阅读候选所在段落，**不能描述为人工逐句读完全部文章，或全库技术事实已经核验**。

本轮没有逐篇联网核验产品、版本、编号和作者主张，也没有批量补来源。维护检查不执行文章代码、PoC、HTML、扫描器、载荷或附件，不访问示例目标，不以维护者实际复现作为验收要求。

## 实际修正

- 为边界明确的原始 HTTP、Java 和调试输出增加或修复独立围栏，避免请求换行折叠、下划线被解释为强调，以及解释和图片被吞入代码区。
- 分隔 HTML 表格与后续 Markdown 标题、强调文字；保留引用层级和表格单元格内容。
- 将说明中讨论的 XML 标签、类型及占位符显示为字面代码；在既有 HTML 表格中仅转义应显示的尖括号，不重写示例含义。
- 完整修复 WPS 的调试输出与解释边界：17 段原始输出分别保留，16 段原有解释回到正文，披露时间表保持在代码区外。仅删除末尾围栏的提案会产生解析差异，因此未采用。
- 修复 KindEditor、Nexus 和 PostgreSQL 文中的围栏边界；补入围栏的原有 SOAP、表单及 multipart 正文保留在同一示例中。
- 将唯一没有图片地址的抓取占位 `![modal content]()` 改为原有替代文字；其他已有非空图片 token 均保留。

新增围栏保留归档中的空行、尾随空格、全角缩进、占位符和公开测试值。网页 Markdown 的源格式仍可能包含不同于实际传输报文的空白或定界符；本轮不将它们清理成假定的报文字节，也不声称这些示例可直接发送。昂捷 SOAP 和 203 项漏洞合集的原有反引号按归档保留，并在示例之外说明这一点。

审阅提案与最终修改分别记录。主维护者撤回了删除抓取原文、广告尾部或残缺链接的建议；WLAN 表格的原值已在正确版本列，不能挪入 CVE 列；Redis 的版本更正已经存在，未重复改写。部分 HTTP 提案仅包含请求头，已依据原文扩展到完整的原有请求体；另有压缩网页空行的提案改为逐字保留。

## 检索修正

`scripts/wiki.py` 现在将已有 `archive_url`、`archive_commit`、`archive_title` 原值投影到来源记录，并取消参考链接列表的 50 条截断。归档链接仍与原始出处 `source.url` 分开，不因此提升核验状态；未声明的字段不补写。

逐值核对确认：3,072 个归档 URL、1,039 个归档提交和 1 个归档标题全部匹配原文；5,664 篇来源记录的链接列表与提取结果一致。原先超过 50 条的 6 篇文章保留全部链接，共恢复投影中遗漏的 149 条链接。查询与字段说明见 [CONTENT-SCHEMA.md](CONTENT-SCHEMA.md)。
