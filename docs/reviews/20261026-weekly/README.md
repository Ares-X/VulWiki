## 静态反投毒与许可

逐篇的固定源码、安装/构建、依赖及工作流范围随正文和分表记录。独立小仓库可完整遍历，Metasploit/LiteLLM 等大型产品只审与具体材料有关的实现及相关入口，不冒充整个生态认证。没有推荐可疑材料为可靠检测器；正常利用中的文件读取、配置修改、创建流程、主动认证绕过与对操作者的无关行为分开。

必要的 LiteLLM 请求图片作为原作者公开技术证据引用，保留原始字节、完整URL与来源版权，不复制整篇研究。图片已有的占位文字来自原作者，不由本库替换；未发现需暂停发布的有效秘密。原文账号、请求值、标识符、URL 和索引不作脱敏。
