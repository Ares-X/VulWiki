- 74 R6900v2: HTTP snippets read configuration/password material and change administrator password/recovery fields. The normal and bypass examples retain id and old-password fields. No standalone downloader or installer; linked firmware, BinDiff and diaphora are not execution dependencies of the summary and were not audited. - 77 DGN1000: HTTP example reads /www/.htpasswd; arbitrary command capability is explicit. Firmware simulation creates privileged TAP networking and runs FirmAE. FirmAE and image provenance not independently audited. No inline Python installer, concealed callback or extra downloader.
- 88 Ruckus: shown Python creates OS users, sets passwords, adds sudo membership; final curl changes sudoers. HTTP callback is explicit. Other grep excerpts include HA crontab changes, removal of corosync files and restarting services; those are vendor code excerpts, not actions this review took. NBD mounting and OVA handling are privileged lab operations. AES key/IV size inconsistency exists in original research too. No successful-runtime assertion. - 92 A3000RU: source changes watchdog behavior, temporarily replaces upgrade.so and restarts cste_sub for analysis. Final injection writes Web content and reaches rm cleanup logic. No complete Python installer is supplied. The source's failed multipart path and working JSON path remain separate; authentication was not proven absent.
- 94 NR1800X: all three request scripts use requests and send explicit command injection or a 4096-character overflow. Their cookies mapping uses key Cookie, not SESSION_ID. The source contains lengthy decompiled login/dispatcher routines, privileged QEMU/tap/mount setup and a debugger listener; no hidden exfiltration is visible in these snippets. Overflow can crash the per-request CGI; author explicitly corrects the earlier crash/restart interpretation. Build mapping is missing, hence no draft.
- 95 SR20: Python socket code sends a UDP request and waits on port61000; no unexpected destination beyond supplied target. Target TFTP fetch and Lua execution are intrinsic to the documented flaw. Netcat callback and telnet service examples are explicit. Lab recipe installs atftpd, creates globally writable service files/directories and host TAP/mount configuration. Python3 response.encode('hex') and Lua # comments are invalid as printed. Existing entity was located and fully read; no second article created.
- 96 AXE75: all source code and necessary archer.py were statically read. The linked original archer.py blob is 1f4d64f15a9aa7aaf13d11e1c97420dbe491ee93; README blob 0fab2b2c1e22ef5358767c6568e5f43f6c7c52bf confirms exact build. Script requests only the chosen router, handles RSA/AES login and sends a user-selected command. Default writes /www/poc.txt. Payload includes a trailing rm -rf that interacts with the appended cp destination; not a harmless probe. Unused download_request writes a server-chosen Content-Disposition filename under cwd without path normalization, a latent local file-write/path-traversal risk if called. It is not called by the main exploit flow. Imports requests and Crypto; no package versions/hashes or license file in root listing. No installer/build/workflow in root. No unrelated callback in archer.py; source demonstration intentionally starts a reverse shell. The earlier authentication-source project is attributed but not recursively imported/audited. Firmware and host /dev,/proc bind mounts are outside trust guarantees.

That local os.system is itself unsafe with untrusted CLI input. requests is unpinned. The external BusyBox/gdbserver binaries and Firmadyne environment were not imported or certified.
